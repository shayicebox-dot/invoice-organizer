# Profit Dashboard

A multi-brand eCommerce profit dashboard that shows **real net profit** —
not vanity revenue — across Kicksbox, ICEBOX, and BRUNO.

Built with Next.js 14 (App Router), TypeScript, Tailwind, Supabase Postgres,
and Claude for daily AI insights.

![Dark, minimal, Stripe/Linear-style UI](./screenshot.png)

---

## What it does

| Page | What you see |
|---|---|
| **Overview** | Net profit, revenue, gross margin, MER, ROAS, CAC, AOV, returning %, today's orders, 30-day trend chart, top AI insights, recent orders |
| **Products** | Per-SKU and per-bundle: units sold, revenue, COGS, net profit, margin %, refund %. Special bundle support (10/20/50-packs) |
| **Orders** | Every order with revenue, ad source, ad cost attribution, shipping, fees, net profit, customer state. Filters: profitable, losing, returning, high AOV |
| **Inventory** | Stock value, sell-through velocity, days-of-stock left, reorder forecast ("will run out around May 31") |
| **Marketing** | Meta / Google / Klaviyo campaigns by spend, attributed revenue, ROAS, **net profit after COGS** |
| **Customers** | LTV, total profit generated, order frequency, refund history, VIP score |
| **AI Insights** | Daily insights generated by Claude. Each one ties to dollars and includes a specific next action |

```bash
# Open Supabase SQL editor, paste contents of supabase/schema.sql, run.

cp .env.example .env.local   # fill in tokens
npm install
npm run dev                   # http://localhost:3000

# 3. Deploy
# Push to GitHub, import to Vercel, root directory = "dashboard",
# paste env vars, deploy.

# 4. First sync
curl -X POST "https://YOUR.vercel.app/api/sync?days=90" \
  -H "x-cron-secret: YOUR_CRON_SECRET"
```

## Stack

- **Frontend**: Next.js 14 App Router, React Server Components, Tailwind CSS,
  recharts, lucide-react
- **Backend**: Next.js API routes (run on Vercel Node runtime, max 300s)
- **Database**: Supabase Postgres (Row-Level Security ready, single-tenant today)
- **AI**: Anthropic Claude Sonnet 4.6 via the official SDK with prompt caching
- **Cron**: Vercel Cron (`vercel.json`)
- **Integrations**: Shopify Admin GraphQL, Meta Marketing API, Google Ads REST,
  Klaviyo Reporting API, exchangerate.host for FX
